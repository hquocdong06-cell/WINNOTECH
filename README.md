# WINNOTech - E-Commerce Tech Store System

Hệ thống website thương mại điện tử bán linh kiện, thiết bị máy tính và công nghệ.

## 🛠 Công nghệ sử dụng
- **Backend:** Node.js, Express.js, MongoDB (Mongoose)
- **Frontend:** React, Vite, Bootstrap
- **Xác thực & Bảo mật:** JWT, Passport, Google OAuth, bcrypt
- **Tích hợp:** Cổng thanh toán VNPay, QR Code, Nodemailer, Gemini AI

## 🚀 Hướng dẫn cài đặt & khởi chạy

### 1. Cài đặt Backend
```bash
npm install
npm run dev
```

### 2. Cài đặt Frontend
```bash
cd frontend
npm install
npm run dev
```

### 3. Công cụ Cơ sở Dữ liệu
- Xuất dữ liệu: `npm run db:export`
- Nhập dữ liệu: `npm run db:import`
